# Risham Soni — Developer Portfolio

A modern, high-performance developer portfolio built with React 19, Vite, and modular CSS architecture.

## 🚀 Getting Started

### Prerequisites
- **Node.js**: `v20.0.0` or higher
- **npm**: `v10.0.0` or higher

### Installation
```bash
npm install
```

### Development
Start the local development server:
```bash
npm run dev
```

### Production Build
Build the optimized application:
```bash
npm run build
```

Preview the production build locally:
```bash
npm run preview
```

### Linting
Run ESLint to check for code quality and syntax issues:
```bash
npm run lint
```

## 🛠️ Tech Stack
- **Framework:** React 19
- **Build Tool:** Vite
- **Styling:** Modular CSS & Tokens
- **Icons & Graphics:** Three.js / Canvas & SVGs
